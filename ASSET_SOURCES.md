# Asset sources

Every external asset used by LUMEN LEARN, with its licence and attribution. The machine-readable
version is `src/data/photo-credits.json`. It is generated by `scripts/fetch-photos.mjs` from
`assets/photo-sources.json` and is also what the in-app `/credits` page renders.

**People in photos.** These photos come from public events (Wikimedia community trainings,
university workshops, graduations). The people shown are not affiliated with Lumen and are **not**
the fictional personas in the demo.

**Children.** We use only photos of adults and campus scenes. The kids and teens pathways use
original illustrations because we do not publish photographs of identifiable children without
documented guardian consent. A licence covers copyright. It is not consent from the person
pictured. A production build should commission its own photography with signed model releases,
and with guardian consent for any minors.

### Where attribution appears

* A credit chip on each photo (author · licence, linked to `/credits`).
* The `/credits` page lists the title, author, linked licence, source and changes.
* This file and the README.

### Candidates considered and rejected

| Source / query | Reason not used |
|---|---|
| Unsplash search API | No anonymous API access (HTTP 401); not used rather than scraping the site |
| Pexels | Requires an API key; not needed |
| Commons photos of secondary/primary pupils (e.g. school march-past practice, classroom groups) | Identifiable minors, with no documented guardian consent for this use |
| Commons award-ceremony photos (Gombe health week) | Off-topic (formal award handovers) |
| ASC Leiden Rietveld collection (1970s Nigeria) | Historical colour cast that doesn't fit a contemporary product |
| "Young and Upcoming Scientist" lab photos | Participants may be minors |
| Lagos skyline panoramas (other crops) | A better-composed 2026 Lagos Island photo was available |

## Reproducing the photos

```bash
node scripts/fetch-photos.mjs
```

The script reads `assets/photo-sources.json`, gets each file's licence metadata from the Wikimedia
Commons API, downloads a 2000 px thumbnail (cached in `assets/.cache/`), grades and encodes the
images, and rewrites `src/data/photo-credits.json`.
